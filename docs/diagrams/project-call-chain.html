02 · Worker 内部调用链

入口在 worker/index.ts，monitor.ts 协调检查与通知，store.ts 持久化状态。虚线表示先核对、后决定是否重发的异常补偿。

  • 通知判断：启用邮件、有效预测新增或更新、新的确认重置；预测过期只清理状态。比较时也检查是否存在待重试通知。
  • 成功保存：邮件已被接受但写库失败时，只重试写库；不要因为退出 SMTP 会话失败而重新发信。
  • 提交不确定：保留待核对记录并结束本轮；下次从读取记录进入核对分支。SMTP 接受表示服务器已接收，不等于已投递到收件箱。
  • 异常核对：下轮检查先处理结果不确定的事件，再考虑重发。找到对应邮件则补写状态；未找到需留投递缓冲，查询失败则暂缓，预测过期后不重发。
  • 当前模块：index.ts → monitor.ts → store.ts / api.ts / domain.ts → emailer.ts / smtp.ts / imap.ts → store.ts。原 Python 模块保留为行为参考和回滚路径。
